# 音源与分离

## 音源选择

优先使用无削波、无二次有损转码、采样率明确的来源。直播翻唱通常含房间声、
平台压缩和伴奏泄漏；录音室原版通常更适合作为伴奏和编排参考，但未必适合
直接提取主唱后送入 RIFT。

开始前记录：

- 来源、演唱者和文件路径。
- 采样率、位深、声道、时长和编码。
- 是否直播、是否已有混响、是否存在和声或叠唱。
- 用作主唱、伴奏、参考，还是辅助 residual。

## 基准分离

当前基准使用 BS-Roformer 124 bands：

```text
SDR vocals: 12.33
SDR instrumental: 18.64
```

先试听普通与 `fullness-level-1` 输出，不默认认为 fullness 更好。判断重点：

- 主唱咬字和齿音是否完整。
- 长音是否有水声、电音或周期性波动。
- 伴奏鼓点和高频瞬态是否清楚。
- 主唱轨中的和声、混响和伴奏泄漏是否会干扰 RIFT。

## 额外分离的边界

Karaoke、去混响和其他模型用于诊断或局部修复，不是固定前置步骤。连续处理
可能造成：

- 辅音和换气损失。
- 元音频谱变薄或发闷。
- F0 跟踪不稳定。
- 分离伪影被 RIFT 放大。

如果需要和声 residual，应比较：

- `Vocals` 与 `instrumental residual`。
- 先 Karaoke 再去混响。
- 先去混响再 Karaoke。
- 不同 Karaoke 模型。

所有候选先截取同一时间窗、统一试听响度并独奏辨认。正式使用时回到原始、
未归一化的完整轨。
