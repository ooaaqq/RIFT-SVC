# 局部修复与混音

## 时间对齐

将翻唱人声与目标伴奏混合前检查：

- 波形相关性和固定偏移。
- 局部节拍是否一致。
- 是否存在速度漂移。
- 开头、结尾和总时长。

对齐值是歌曲专属参数。应记录偏移方向、毫秒数和证据，不能把一首歌的
`10 ms` 直接当作其他歌曲默认值。

## 局部修复规则

- 修复窗前后至少保留 1 至 2 秒上下文试听。
- 使用余弦或等功率交叉淡化。
- 先匹配电平包络，再考虑频谱或 F0。
- 长音有波动时，先判断波动来自输入还是 RIFT。
- 不用另一位歌手的音色直接替换，除非 AB 证明无法听出边界。
- 重放、回声与和声保留为独立 stem，不写死进主唱轨。

## 当前稳定混音起点

以下是经过歌曲制作验证的起点，不是所有素材的固定标准：

```text
主唱高通             65 Hz
主唱增益             约 +3 dB
主唱压缩             RMS, 1.6:1, 轻度
并行压缩             关闭
伴奏侧链             关闭
短房间返回           关闭
空间                 M7 Studio B Far
M7 预延迟            26 ms
M7 湿声              相对干声 RMS 约 -22 dB
母线压缩             轻度
最终峰值             约 -1.8 dBFS
目标响度             约 -14 LUFS
```

每次先用简单电平平衡判断素材本身，再加入 EQ、压缩和空间。若人声与伴奏不
融合，应依次检查对齐、频谱遮蔽、电平自动化和空间，而不是同时堆叠插件。
